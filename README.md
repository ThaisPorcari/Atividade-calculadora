🧮 Calculadora Interativa em Python
Este repositório contém uma aplicação de calculadora robusta executada diretamente no terminal. O projeto foi estruturado com foco em modularidade, legibilidade de código e tratamento de exceções básicas (como a divisão por zero).

🚀 Funcionalidades
Soma (+): Realiza a adição de dois números reais.
Subtração (-): Calcula a diferença entre dois números reais.
Multiplicação (x): Realiza o produto de dois números reais.
Divisão (/): Calcula o quociente, contendo uma validação para impedir divisões por zero de forma segura.
Menu Interativo: Ciclo contínuo de execução (while True) que permite realizar múltiplos cálculos sem a necessidade de reiniciar o programa.
🛠️ Tecnologias Utilizadas
Linguagem: Python 3.x
Paradigma: Programação Estruturada e Modular (uso de funções)
📁 Estrutura do Código
O código é dividido em duas partes principais:

Funções Matemáticas: Funções isoladas para cada operação, garantindo que o código seja limpo e fácil de dar manutenção.
somar(a, b)
subtrair(a, b)
multiplicar(a, b)
dividir(a, b)
Fluxo de Controle (Menu): Um laço de repetição que interage com o usuário, recebe as entradas, valida a opção escolhida e exibe os resultados de forma amigável.
💻 Como Executar o Projeto
Pré-requisitos
Ter o Python 3 instalado em sua máquina.

Passo a Passo
Copie o código do seu notebook.
Cole em um arquivo local chamado calculadora.py.
Abra o terminal na mesma pasta do arquivo e execute:
python calculadora.py
Siga as instruções exibidas na tela para realizar as operações.

 --- CALCULADORA PYTHON ---
1 - Somar 
2 - Subtrair
